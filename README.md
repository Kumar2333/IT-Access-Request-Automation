# IT Access Request Automation

## Overview

An automated IT access request approval workflow developed using Microsoft Power Platform.

The solution digitizes the manual IT access request process by allowing users to submit requests through SharePoint and automatically routing them for approval using Power Automate.

---

## Technologies Used

- Microsoft SharePoint
- Microsoft Power Automate
- Microsoft Lists
- Microsoft Forms
- Microsoft Outlook Connector

---

## Workflow

1. User submits an IT access request
2. Request details are stored in SharePoint List
3. Power Automate detects new request submission
4. Approval request is automatically sent to the assigned approver
5. Approver reviews the request and selects:
   - Approve
   - Reject
6. SharePoint status is updated automatically
7. Email notification is sent to the requester

---

## Features

✅ Automated approval workflow  
✅ Real-time request status tracking  
✅ Automatic email notification  
✅ Reduces manual IT request processing  
✅ Centralized request management using SharePoint
